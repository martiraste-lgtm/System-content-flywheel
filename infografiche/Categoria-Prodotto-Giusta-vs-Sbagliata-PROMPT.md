# Prompt per tool AI esterni (Gemini / Banana / Midjourney)

Infografica companion del pillar "Guida al Posizionamento — I 3 elementi": la **categoria di prodotto** come frame mentale che il buyer del segmento core ti assegna prima di parlarti. Comparativa **categoria sbagliata (rosso) vs giusta (verde)** + metodo per trovarla + frase di reset del frame. Reference concettuale: Alexander Shartsis ("category losses / perdite invisibili"), riletta con la catena di Stefano (la categoria è il layer *anchor*, a valle di tesi e strategia) — NON clonata.

La fonte autorevole del layout è il file `Categoria-Prodotto-Giusta-vs-Sbagliata.jsx`. Sistema colore della serie: 🟪 Tesi=viola · 🟧 Architetture=arancio · 🔵 Strategia=blu; questa tavola è una **comparativa** (rosso/verde) e usa l'arancio solo come accento neutro del titolo.

⚠️ Le due colonne del confronto hanno **6 righe speculari** (stessa etichetta a sinistra e a destra: Confronto / Criteri / Prezzo / Esito / Percezione / Ciclo): riproducile riga per riga, allineate, con esito opposto.
