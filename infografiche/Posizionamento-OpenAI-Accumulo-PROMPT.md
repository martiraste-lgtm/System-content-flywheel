## Note di contenuto (dati verificati giugno 2026)
OpenAI = anti-esempio "everything-platform". POV orizzontale (Altman: AI utility a consumo) che autorizza l'accumulo: 7+ tracce di prodotto (ChatGPT, GPT-5.5 API, Codex, Operator, gpt-image, Whisper, Embeddings, Sora). Sora: app/web chiusa 26 apr 2026, API in dismissione 24 set 2026. Problema: nessuna frase-ancora, hub di prodotti, leggibile solo grazie a ChatGPT. Perché può permetterselo: ~900M utenti settimanali, ~$25B run rate ($2B/mese), valutazione ~$850B verso ~$1T all'IPO (Q4 2026 possibile). Lezione: la distribuzione compra il diritto all'opacità — un founder early-stage non ce l'ha.
