## Come cresce questo sistema

Ogni volta che:
- Analizzo un autore → si aggiunge una voce in `references/`
- Pubblico un pezzo → si aggiunge una voce in `posts/published.md`
- Osservo un pattern inatteso → si aggiunge in `craft/false_beliefs.md`
- Nasce un'ipotesi → si aggiunge in `hypotheses/active.md`
- Un'ipotesi si conferma 3 volte → diventa regola in `platforms/[platform]/rules.md`

Il sistema non è completo. È un organismo vivo.
