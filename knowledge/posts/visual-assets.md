**Tema**: Il test del posizionamento orizzontale (prodotto singolo, più segmenti) — esempio Calendly
**Post associato**: `articoli/Valore-Positioning-Mistral-OpenAI-Anthropic-2026-06.md` (companion sezione architetture / single-product)
**Funnel**: MoF
**Formato**: JSX (React artifact), layout matrice landscape ~1180px, brand system chiaro

**Contenuto sintetico**:
- Concetto 1: prodotto singolo → azienda = prodotto (box "Calendly = Calendly", un solo positioning)
- Concetto 2: posizionamento orizzontale OK solo se i segmenti condividono lo stesso use case funzionale (= l'ancora)
- Test in 3 step: (1) capability/feature/benefit (uguali per tutti) → (2) persona + tipo azienda → (3) come fa oggi / use case / problema
- Matrice Calendly: Sales / HR / Insegnanti → contesti diversi, stesso use case "fissare un meeting" (colonna Use Case evidenziata = ancora)
- Regola ✅/❌: se gli use case divergono → niente orizzontale, serve positioning più stretto o soluzioni verticali. Il positioning resta uno; cambiano messaging/esempi/benefit per segmento

**Reference usata (non clonata)**: "Horizontal Positioning Test" di Calendly/Fletch. Riadattata al brand system di Stefano (palette chiara, IT/EN naturale) + aggiunto il box "prodotto singolo = azienda".

**Post associato**: *(da collegare)* — origine: schizzo a mano di Stefano
**Funnel**: ToF/MoF
**Formato**: JSX (React artifact), verticale **1080×1350** (LinkedIn), sfondo chiaro, senza firma

**Contenuto sintetico**:
- Struttura fedele allo schizzo a mano di Stefano (resa verticale): titolo "Posizionamento early stage · Da 1.000€ a 30/50 mila € MRR"
- Titoli colorati a testo + pannelli con sfondo sfumato (rosa/verde). CATTIVO (rosso) = "IL TUO PRODOTTO" → frecce divergenti → 3 Target (con ⚠️), **3 catene parallele identiche** (Use Case → Offerta → Canale → Asset: H.P./Sales Deck → Casi Studio) = tutto triplicato. BUON (verde lime) = "IL TUO PRODOTTO" → 4 Target potenziali ma **ne scegli UNO**: i 3 scartati grigi impilati a sinistra, Target 4 evidenziato lime + ✓ + glow a destra con la catena (1 Use Case, 1 Offerta… Casi Studio unici) costruita **sul target scelto** = Focus (caption: "1 target, 1 use case, 1 offerta, 1 asset → Focus").

- Nessun footer (rimosso su richiesta).

**Reference usata (non clonata)**: "Bad vs Good Positioning" di Fletch — ne ricorda la struttura (prodotto in cima → target sotto) ma **tutti i nodi sono quadrati/rettangoli, non i cerchi di Fletch**. Il contrasto è reso fedelmente allo schizzo: 3 catene parallele identiche (cattivo) vs 4 target potenziali tra cui se ne SCEGLIE uno, con la catena costruita solo sul target scelto (buon).

**⭐ Versione finale approvata da Stefano** — è il modello di riferimento per lo stile "comparativa cattivo/buon" (**Variante A — due diagrammi paralleli**). - Sez.3 Cattiva vs Buona tesi: la cattiva mostra **le due trappole opposte** (🔒 chiudi troppo presto / 🌀 non chiudi mai — dopo anni ancora su segmenti diversi); la buona = àncora il problema, varia un asse alla volta, ascolta, **chiudi sul pattern (criterio d'uscita)**. + box-nota "🛑 Use case/Homepage/Sales deck/Value prop → li SCOPRI, non bloccarli ora"
