**Tema**: Il test del posizionamento orizzontale (prodotto singolo, più segmenti) — esempio Calendly
**Post associato**: `articoli/Valore-Positioning-Mistral-OpenAI-Anthropic-2026-06.md` (companion sezione architetture / single-product)
**Funnel**: MoF
**Formato**: JSX (React artifact), layout matrice landscape ~1180px, brand system chiaro

**Contenuto sintetico**:
- Concetto 1: prodotto singolo → azienda = prodotto (box "Calendly = Calendly", un solo positioning)
- Concetto 2: posizionamento orizzontale OK solo se i segmenti condividono lo stesso use case funzionale (= l'ancora)
- Test in 3 step: (1) capability/feature/benefit (uguali per tutti) → (2) persona + tipo azienda → (3) come fa oggi / use case / problema
- Matrice Calendly: Sales / HR / Insegnanti → contesti diversi, stesso use case "fissare un meeting" (colonna Use Case evidenziata = ancora)
- Regola ✅/❌: se gli use case divergono → niente orizzontale, serve positioning più stretto o soluzioni verticali. Il positioning resta uno; cambiano messaging/esempi/benefit per segmento

**Reference usata (non clonata)**: "Horizontal Positioning Test" di Calendly/Fletch. Riadattata al brand system di Stefano (palette chiara, IT/EN naturale) + aggiunto il box "prodotto singolo = azienda".
