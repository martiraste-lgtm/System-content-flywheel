# Log — Substack Notes

Una riga per ogni Note pubblicata. Si compila **dopo** la pubblicazione, non prima.
Stesso principio del `radar/log.md`: tabella asciutta, la sintesi in chiaro sotto.

Le metriche si rilevano a 48-72 ore dalla pubblicazione (le Notes hanno una coda breve).

---

## Notes pubblicate

| Data | Numero di origine | Blocco | Formato | Restack | Like | Commenti | Iscritti (giorno) | Nota |
|------|-------------------|--------|---------|---------|------|----------|-------------------|------|
| | | | | | | | | |

**Colonne:**
- **Blocco** — da dove viene: `campagna-1/2/3`, `tool`, `provocazione`, `reazione` (non derivata dal numero)
- **Formato** — quello assegnato dalla skill
- **Restack** — il dato che conta di più se H1 regge. Annotare tra parentesi se il restack viene da un account con audience rilevante
- **Iscritti (giorno)** — nuovi iscritti nelle 24h. Indicatore ritardato e rumoroso: non decidere niente su una riga sola
